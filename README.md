### 📦 Open Source

[![django-smart-ratelimit stars](https://img.shields.io/github/stars/YasserShkeir/django-smart-ratelimit?style=flat-square&label=%E2%98%85&color=0f6b5c)](https://github.com/YasserShkeir/django-smart-ratelimit)
[![django-smart-ratelimit downloads](https://img.shields.io/pypi/dm/django-smart-ratelimit?style=flat-square&label=django-smart-ratelimit&color=3775A9)](https://pypi.org/project/django-smart-ratelimit/)

**[django-smart-ratelimit](https://github.com/YasserShkeir/django-smart-ratelimit)** — High-performance
distributed rate limiting for Django. Four algorithms (token bucket, sliding window, fixed window,
leaky bucket) as atomic Redis Lua operations, sync + async decorators, circuit breaker and
automatic failover, shadow mode for zero-risk rollout, pluggable backends, Prometheus +
OpenTelemetry observability, runtime-editable rules, DRF throttles and GraphQL middleware.
Django 3.2–6.0.

[![django-safe-migrations stars](https://img.shields.io/github/stars/YasserShkeir/django-safe-migrations?style=flat-square&label=%E2%98%85&color=0f6b5c)](https://github.com/YasserShkeir/django-safe-migrations)
[![django-safe-migrations downloads](https://img.shields.io/pypi/dm/django-safe-migrations?style=flat-square&label=django-safe-migrations&color=3775A9)](https://pypi.org/project/django-safe-migrations/)

**[django-safe-migrations](https://github.com/YasserShkeir/django-safe-migrations)** — Static analysis
that catches unsafe migrations before they reach production. 36 rules across 14 categories
(table locks, data loss, SQL injection, schema/state mismatch), PostgreSQL-aware, with GitHub
Actions / GitLab Code Quality / SARIF output, baseline suppression, and git-diff mode for CI.

[![torpor stars](https://img.shields.io/github/stars/YasserShkeir/torpor?style=flat-square&label=%E2%98%85&color=0f6b5c)](https://github.com/YasserShkeir/torpor)

**[torpor](https://github.com/YasserShkeir/torpor)** — macOS menu-bar app for Claude Code sessions.
Shows what each session actually costs in memory (including the MCP child processes Activity
Monitor misattributes) and hibernates the idle ones without losing them. Swift, `brew install`.

[![sluice stars](https://img.shields.io/github/stars/YasserShkeir/sluice?style=flat-square&label=%E2%98%85&color=0f6b5c)](https://github.com/YasserShkeir/sluice)

**[sluice](https://github.com/YasserShkeir/sluice)** — Local-only interceptor and explorer for your
own SaaS API traffic. Capture, normalise and replay what the apps you already use are actually
calling — MITM proxy, token extraction, or passive CDP capture. CLI, web dashboard, MCP server.
